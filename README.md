# Inferno Knight

**Play here:** [https://aaravpvcsai.github.io/inferno-knight-play/](https://aaravpvcsai.github.io/inferno-knight-play/)

A single-player HTML5 platformer. Open the link above to play in any browser and share with friends.

### Controls
- Move: A/D or arrows
- Jump / double jump: Space / W
- Attack: Z / X / click
- Roll: Shift+A (back) or Shift+D (forward)
- Rarjon flight: tap F to flap
